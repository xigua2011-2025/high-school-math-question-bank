# 高中数学题库

用于存放高中数学练习题的原始题目数据，作为题库的唯一来源（Source of Truth）。

## 目录结构

```text
high-school-math-question-bank/
├── README.md
├── index.json
└── 人教B版/
    └── 高一上/
        ├── 01-集合/
        ├── 02-等式与不等式/
        ├── 03-函数/
        └── ...
```

## 文件规范

每道题使用唯一 ID，并尽量保存三种格式：

- `.json`：结构化题目数据、答案、解析、标签
- `.md`：适合阅读的 Markdown 版本
- `.tex`：LaTeX 数学排版版本

推荐 ID 格式：`MATH-B-G1-章节号-题号`

例如：`MATH-B-G1-01-024`

## 与 Notion 的分工

- GitHub：保存原题、答案、解析、知识点、模型等稳定题库数据。
- Notion：保存实际学习记录，包括做对/做错、错误原因、掌握度、复习记录等动态数据。

目标：根据历史练习记录，自动减少已经掌握的重复题，并优先筛选真正需要训练的题目。
